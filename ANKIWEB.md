Larger or more specialized Anki collections often rely on custom fields to organize different kinds of content. As a collection develops, tacit conventions emerge about the meaning and use of those fields and tags. These conventions are essential collection-level metadata for interpreting the collection correctly, not least when notes are assessed with or generated by an LLM.

Ideally this documentation should reside within the collection itself rather than in an external file. One simple way to achieve this is to store a field and tag legend as an HTML comment in a card template: the text remains hidden during review but is easy to inspect or edit and stays with the collection. This add-on exports the complete legend as plain text with a single command, either to the clipboard or to a file.

**Export Field & Tag Legend as Text** is designed to complement **[Selected Notes to Structured Text](https://ankiweb.net/shared/info/1694585841)** and **[Export Tags as Text](https://ankiweb.net/shared/info/550673409)**. The first exports selected notes, the second exports the collection-wide tag inventory, and this add-on exports the conventions that explain the fields and tags.

## Usage

Choose either of the following menu items:

* **Tools → Copy Field & Tag Legend as Text**
* **Tools → Save Field & Tag Legend as Text…**

Both commands export the same legend: **Copy Field & Tag Legend as Text** places it on the clipboard; **Save Field & Tag Legend as Text…** writes it to a UTF-8 text file, by default named `anki-field-tag-legend-YYYY-MM-DD.txt`.

## Configuration

The legend location, marker, and keyboard shortcuts can be changed under **Tools → Add-ons → Export Field and Tag Legend as Text → Config**. The default configuration is:

    {
        "location": {
            "card_type": "Card 1",
            "note_type": "Basic"
        },
        "marker": "# FIELD & TAG LEGEND",
        "shortcut_copy": "",
        "shortcut_save": "Meta+Ctrl+Shift+L"
    }

### Location

`location.note_type` and `location.card_type` specify the note type and card type whose front template contains the legend.

### Marker

The legend must be stored in an HTML comment containing the configured marker:

    <!--
    
    # FIELD & TAG LEGEND
    
    [Legend goes here.]
    
    -->

The marker must occur exactly once in the configured front template. The comment delimiters `<!--` and `-->` and any leading or trailing whitespace are not included in the exported text. If the configured note type or card type cannot be found, the marker is missing or occurs more than once, or the marker is not inside a complete HTML comment, the add-on reports the problem and exports nothing.

The add-on only reads the template; it does not modify the template or any other part of the collection.

### Shortcuts

`shortcut_save` sets the shortcut for **Save Field & Tag Legend as Text…** The default shortcut is `Meta+Ctrl+Shift+L` (`⌃⇧⌘L`); set it to `""` to disable it. `shortcut_copy` sets the shortcut for **Copy Field & Tag Legend as Text**. It is disabled by default. No restart is required.

## Format

The exported text is the contents of the matching HTML comment. The `<!--` and `-->` delimiters are omitted, leading and trailing whitespace is removed, and internal line breaks and spacing are preserved.

For example, the template comment:

    <!--
    
    # FIELD & TAG LEGEND
    
    ## Field Legend
    
    `NTS` — Notes
    
    ## Tag Legend
    
    `#df` — Definition
    
    -->

is exported as:

    # FIELD & TAG LEGEND
    
    ## Field Legend
    
    `NTS` — Notes
    
    ## Tag Legend
    
    `#df` — Definition
     

## Compatibility

Tested with Anki 26.08 on macOS Tahoe 26.5. Windows and Linux have not yet been tested.
